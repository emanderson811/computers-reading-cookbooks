What is computational text analysis?

A research method in which a computer “reads” hundreds (or thousands) of texts, allowing the researcher to identify and analyze patterns in word usage.

  1. ↔

    1. Scan the cookbooks

    Each cookbook is scanned to create image files of each page.

  2. ≋

    2. Recognize the text

    Optical character recognition (OCR) converts the text within each image file to text files a computer can “read.”

  3. ✳

    3. Explore the patterns

    Explore these text files to reveal trends and enhance our understanding of Iowa food history and culture using software designed to analyze text.
